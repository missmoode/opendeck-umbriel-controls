# Umbriel Controls

Generates a Noctalia colour palette for
[Umbriel Controls](https://github.com/missmoode/opendeck-umbriel-controls), an OpenDeck
plugin for the Umbriel compositor.

## Setup

1. Install Umbriel Controls and enable this template in Noctalia's **Settings →
   Templates**.
1. In an Umbriel Controls action's property inspector, expand Global Settings and select
   **noctalia (Custom)** as the default palette.

The template writes to:

`$XDG_CONFIG_HOME/opendeck/settings/dev.moode.umbriel-controls.sdPlugin/palettes/noctalia.json`
